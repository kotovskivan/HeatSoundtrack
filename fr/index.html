HEATSoundtrack

Tes propres chansons dans Need for Speed Heat — en nouveaux titres, juste à côté de ceux du jeu.

BientôtCode source

Gratuit · Windows 10/11 · Solo uniquement · Fait par des fans

Ce qu'il fait

Tes chansons

mp3, flac, wav, ogg, m4a — ajoutées comme nouveaux titres. Les titres du jeu restent tels quels.

Jour · Nuit

Coche où passe chaque chanson : garage, ville de jour, ville de nuit, courses de jour, courses de nuit.

Titres du jeu

Active ou désactive n'importe quel titre du jeu — séparément pour chaque endroit.

YouTube · YT Music

Colle le lien d'une chanson, d'une playlist ou d'un album — ou plein de liens d'un coup. Avec le lien d'un clip, le programme prend la même chanson sur YT Music.

Un seul mod

Crée un seul mod pour Frosty Mod Manager. Les fichiers du jeu ne sont pas modifiés. Profils : différentes sélections de titres, on change en un clic.

14 langues

La fenêtre parle 14 langues. Ni musique ni fichiers du jeu dans le zip — les chansons, c'est toi qui les apportes.

Ce qu'il te faut

  1. Windows 10 ou 11 — Microsoft Edge est intégré, la fenêtre l'utilise.
  2. Need for Speed Heat — Steam ou EA app.
  3. Frosty Mod Manager, la version de HarGabt — versions. Lance-le une fois et choisis le jeu.
  4. La clé de chiffrement du jeu — NFS Heat Frosty Key sur Nexus Mods : mets NFSHEAT.key dans le dossier de Frosty Mod Manager.

Comment l'utiliser

  1. Décompresse tout le zip dans un dossier normal — Bureau, Documents, D:\Mods… — pas dans Program Files.
  2. Lance Heat Soundtrack.exe, choisis la langue et accepte les conditions. Le premier lancement lit le jeu — quelques minutes, une seule fois.
  3. + AJOUTER UNE CHANSON → choisis un fichier → coche où elle passe → Enregistrer. Ou ▶ DEPUIS YT MUSIC → colle un lien → Télécharger.
  4. Les chansons sont dans le dossier Music à côté du programme — un dossier numéroté par chanson : le fichier de la chanson et une image pour la pochette.
  5. CRÉER LE MOD. Le mod apparaît dans la liste de Frosty Mod Manager.
  6. Dans Frosty Mod Manager : coche Heat Soundtrack, désactive les autres mods de musique, appuie sur Launch.

Hors ligne uniquement. Les mods sont faits pour le jeu solo. Avant de jouer en ligne, lance le jeu sans mods — jouer en ligne avec des mods peut faire bannir ton compte EA.

Windows SmartScreen peut avertir d'un éditeur inconnu : le programme n'a pas de certificat payant. Clique sur Informations complémentaires → Exécuter quand même. Le code source est sur GitHub.
