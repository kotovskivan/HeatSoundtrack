HEAT SOUNDTRACK  v1.0
Свої пісні в Need for Speed Heat — як нові треки поруч із треками гри.
Безкоштовна фанатська програма від Kitivski + Claude. НЕ пов'язана з Electronic Arts чи Ghost Games.

English — README.txt поруч із програмою.
Переклади зроблені ШІ (Claude).

=====================================================================
ЩО ВМІЄ
  - Вмикати/вимикати треки гри: гараж, місто вдень, місто вночі, гонки вдень, гонки вночі.
  - Додавати свої пісні (mp3, flac, wav, ogg, m4a) як НОВІ треки й обирати галочками, де кожна грає.
    Треки гри лишаються як є.
  - Пісні з YouTube / YT Music: посилання на пісню, плейлист чи альбом, багато посилань разом або список у .txt.
    Якщо посилання на кліп, програма бере ту саму пісню з YT Music — без вставок і сценок із кліпу.
  - Spotify: посилання на пісню, альбом чи плейлист (до 100 пісень за посиланням; більший плейлист — файлом .csv з exportify.app).
    Зі Spotify береться лише список — самі пісні завантажуються з YT Music.
  - Старт гонки зі своєю піснею: познач дроп — кадри заставки й відлік 3-2-1 підуть під твою пісню, дроп ударить одразу після GO!. Дроп програма може знайти сама.
  - Виїзд з гаража: флажок на хвилі — звідки грає пісня, коли виїжджаєш із гаража. Не чіпав — програма бере найгучніше місце.
  - Гучність кожної пісні: 0–300 %, «Авто» й захист від перевантаження.
  - «Без диктора»: мовчать Ана, розмови в їзді й диктор меню; катсцени як є.
  - Профілі: різні набори треків, перемикання в один клік.
  - Збирає ОДИН мод для Frosty Mod Manager. Файли гри не змінюються.
  - Вікно розмовляє 14 мовами.

ЩО ПОТРІБНО
  - Windows 10 або 11 (Microsoft Edge вже вбудований — вікно працює на ньому).
  - Need for Speed Heat (Steam або EA app).
  - Frosty Mod Manager, версія HarGabt для NFS Heat:
    https://github.com/HarGabt/FrostyToolsuite/releases
    Запусти його один раз і обери гру, перш ніж користуватися цією програмою.
    Під час першого запуску він просить ключ шифрування гри — NFS Heat Frosty Key (Nexus Mods).
    https://www.nexusmods.com/needforspeedheat/mods/74   (NFSHEAT.key -> Frosty Mod Manager\)
    Коли вперше натиснеш Launch (і після видалення папки ModData), Frosty просить права адміністратора,
    щоб створити посилання на дані гри ("New installation detected") — це нормально, погоджуйся.

ЯК КОРИСТУВАТИСЯ
  1. Розпакуй УВЕСЬ zip у звичайну папку (Робочий стіл, Документи, D:\Mods…),
     не в Program Files.
  2. Запусти "Heat Soundtrack.exe".
  3. Обери мову, прийми умови. Перший запуск читає гру — кілька хвилин, лише раз.
  4. + ДОДАТИ ПІСНЮ → обери файл → постав галочки, де грає → Зберегти.
     Або ▶ З YT MUSIC → встав посилання (пісня, плейлист, альбом) → Завантажити.
     Усі пісні лежать у папці "Music" поруч із програмою, кожна в папці з номером:
     Music\1\, Music\2\… — це порядок у вікні. + ДОДАТИ ПІСНЮ сама створює наступну папку.
     Вручну: нова папка з номером, у ній файл пісні + картинка (jpg, png) для обкладинки.
     Видалив папку — пісня зникне з програми.
     Картинка: назва будь-яка, якщо вона в папці одна; кілька — береться cover.jpg. Розмір будь-який.
     Обкладинка — лише для програми: у мод і в гру вона не йде (у Heat у треків немає обкладинок).
  5. ЗІБРАТИ МОД. Мод з'явиться у списку Frosty Mod Manager.
  6. У Frosty Mod Manager: постав галочку на "Heat Soundtrack", інші музичні моди вимкни, натисни Launch.

ТІЛЬКИ ОФЛАЙН
  Моди — для одиночної гри. Перш ніж іти в онлайн, запускай гру без модів.
  Гра онлайн з модами — ризик бану акаунта EA.

"WINDOWS ЗАХИСТИВ ВАШ ПК" / "НЕВІДОМИЙ ВИДАВЕЦЬ"
  Програма не підписана платним сертифікатом, тому Windows SmartScreen про неї попереджає.
  Натисни "Докладніше" → "Однаково запустити". Вихідний код — у папці "source".

ЩО В ПАПЦІ
  Heat Soundtrack.exe      програма
  app\web                  вікно (сторінки, тексти 14 мовами)
  app\frosty               бібліотеки Frosty Toolsuite — читають гру, записують мод (GPL v3)
  app\encoder              аудіокодувальник EA з плагіна Sound Editor для Frosty Editor
  app\yt-dlp.exe           качає пісні з YouTube / YT Music (Unlicense)
  source\                  вихідний код цієї програми (GPL v3)
  README\                  цей текст іншими мовами
  data\                    з'являється при першому запуску: твої налаштування, пісні, картинки з ТВОЄЇ гри, лог
  Music\                   твої пісні, кожна в папці з номером: файл пісні, обкладинка, song.json (виконавець, назва)
  THIRD-PARTY.txt          що використовуємо, автори, ліцензії, посилання
  Файлів гри чи EA в архіві немає: фони читаються з твоєї власної гри.

ЯКЩО ЩОСЬ НЕ ПРАЦЮЄ
  - Лог — data\log.txt (кнопка "Лог" у вікні).
  - Після оновлення гри програма сама перечитає гру. Якщо збирання падає з помилкою
    "Гра змінилася" — пошукай новішу версію програми.
  - Почати заново: закрий програму й видали папку "data".

ЯК ВИДАЛИТИ
  Вимкни мод у Frosty Mod Manager і видали папку з програмою.
