할 수 있는 것

내 노래

mp3, flac, wav, ogg, m4a — 새 트랙으로 추가돼요. 게임 트랙은 그대로 남아요.

낮 · 밤

노래마다 나올 곳을 체크하세요: 차고, 낮 도시, 밤 도시, 낮 레이스, 밤 레이스.

게임 트랙

게임 트랙은 어떤 것이든 켜고 끌 수 있어요 — 장소마다 따로.

YouTube · YT Music

노래, 재생목록, 앨범 링크를 붙여 넣으세요 — 여러 링크를 한꺼번에 넣어도 돼요. 뮤직비디오 링크면 같은 노래를 YT Music에서 가져와요.

모드 하나

Frosty Mod Manager용 모드를 딱 하나 만들어요. 게임 파일은 바뀌지 않아요. 프로필: 트랙 구성을 여러 개 만들고 클릭 한 번으로 바꿔요.

13개 언어

창은 13개 언어를 지원해요. zip에는 음악도 게임 파일도 없어요 — 노래는 직접 넣어요.

필요한 것

  1. Windows 10 또는 11 — Microsoft Edge가 기본으로 들어 있고, 창이 Edge를 사용해요.
  2. Need for Speed Heat — Steam 또는 EA app.
  3. Frosty Mod Manager, HarGabt 버전 — 릴리스. 한 번 실행해서 게임을 선택하세요.
  4. 게임 암호화 키 — Nexus Mods의 NFS Heat Frosty Key: NFSHEAT.key를 Frosty Mod Manager 폴더에 넣으세요.

사용법

  1. zip을 통째로 일반 폴더에 압축 해제하세요 — 바탕 화면, 문서, D:\Mods… — Program Files 말고요.
  2. Heat Soundtrack.exe를 실행하고 언어를 고른 뒤 약관에 동의하세요. 처음 실행할 때 게임을 읽어요 — 몇 분 걸리지만 딱 한 번이에요.
  3. + 노래 추가 → 파일 선택 → 재생 위치 체크 → 저장. 또는 ▶ YT Music에서 → 링크 붙여 넣기 → 다운로드.
  4. 노래는 프로그램 옆 Music 폴더에 있어요 — 노래마다 번호 폴더 하나: 노래 파일과 커버 그림.
  5. 모드 만들기. 모드가 Frosty Mod Manager 목록에 나타나요.
  6. Frosty Mod Manager에서: Heat Soundtrack에 체크하고, 다른 음악 모드는 끄고, Launch를 누르세요.

오프라인 전용. 모드는 싱글 플레이 전용이에요. 온라인에 접속하기 전에 모드 없이 게임을 실행하세요 — 모드를 켠 채 온라인을 하면 EA 계정이 정지될 수 있어요.

Windows SmartScreen이 알 수 없는 게시자라고 경고할 수 있어요: 이 프로그램에는 유료 인증서가 없거든요. 추가 정보 → 실행을 클릭하세요. 소스 코드는 GitHub에 있어요.
