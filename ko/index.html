01할 수 있는 것

내 노래

mp3, flac, wav, ogg, m4a — 내 제목을 단 새 트랙으로. 게임 원곡을 대체하지 않습니다. 모드 하나에 노래 수백 곡.

YouTube · YT Music · Spotify

노래, 플레이리스트, 앨범 링크를 붙여 넣거나 여러 링크, .txt 목록을 넣으면 됩니다. 다운로드는 프로그램이 알아서 합니다. 뮤직비디오 링크면 YT Music의 같은 노래를 인트로와 장면 없이 가져옵니다. Spotify 링크도 됩니다: 목록은 Spotify에서, 노래는 YT Music에서 가져옵니다.

GO에 드롭

출발: 컷신 17초 + 카운트다운 3.45초, GO에 드롭이 딱 맞습니다. GO 표시는 마우스로 끌어서 옮깁니다. 결승선 뒤의 짧은 구간도 설정합니다.

차고 · 도시 · 레이스

노래마다 나올 곳을 체크하세요: 차고, 낮 도시, 밤 도시, 낮 레이스, 밤 레이스. 게임 원곡도 마찬가지로 장소별로 따로. 음악 세트별 프로필도 만들 수 있습니다.

모드 하나

Frosty Mod Manager용 모드를 하나 만듭니다. 게임 파일은 바뀌지 않습니다 — 모드를 끄면 원래대로입니다.

깨끗한 zip

zip에는 음악도 게임 파일도 없습니다. 노래는 당신의 것이고, 게임 원곡은 당신의 게임에서 읽어옵니다. ▶︎ — 게임 트랙 30초 미리 듣기(인터넷 필요).

02스크린샷

03필요한 것

  1. Windows 10 또는 11 — Microsoft Edge가 기본으로 들어 있고, 창이 Edge를 사용해요.
  2. Need for Speed Heat — Steam 또는 EA app.
  3. Frosty Mod Manager, HarGabt 버전 — 릴리스. 한 번 실행해서 게임을 선택하세요.
  4. 게임 암호화 키 — Nexus Mods의 NFS Heat Frosty Key: NFSHEAT.key를 Frosty Mod Manager 폴더에 넣으세요.

04NFS Heat에 내 음악을 넣는 방법

  1. zip 전체를 일반 폴더에 압축 해제 — 바탕 화면, 문서, D:\Mods… Program Files에는 넣지 마세요.
  2. Heat Soundtrack.exe를 실행하고 언어를 고른 뒤 약관에 동의하세요. 처음 실행할 때 게임을 읽어요 — 몇 분 걸리지만 딱 한 번이에요.
  3. + 노래 추가 → 파일 선택 → 재생 위치 체크, GO와 결승 설정 → 저장.또는 ▶︎ YT Music에서 → 링크 붙여 넣기(노래, 재생목록, 앨범). 여러 링크나 .txt 목록도 가능 → 다운로드.뮤직비디오 링크면 YT Music의 같은 노래를 인트로와 장면 없이 가져옵니다. 플레이리스트 전에는 곡 수, 이미 있는 곡, 시간과 용량을 보여 주고, 이미 있는 곡은 건너뜁니다. .txt 목록: 제목,아티스트,링크; (라틴 문자로) — 예시 파일은 프로그램에 있습니다.노래는 프로그램 옆의 Music 폴더에, 한 곡씩 번호 폴더로 들어 있습니다: Music\1\, Music\2\… 직접 해도 됩니다: 번호를 붙인 새 폴더에 노래 파일과 이미지를 넣으면 끝. 커버는 이 프로그램에서만 보이고, 게임에는 들어가지 않습니다.
  4. 모드 만들기. 모드가 Frosty Mod Manager 목록에 나타나요.
  5. Frosty Mod Manager에서 Heat Soundtrack을 체크하고, 다른 음악 모드는 끈 뒤 Launch.

오프라인 전용

모드는 싱글 플레이용입니다. 온라인으로 하기 전에 게임을 모드 없이 실행하세요. 모드를 켠 채 온라인을 하면 EA 계정이 정지될 수 있습니다.

“Windows의 PC 보호”

유료 인증서로 서명하지 않아서 SmartScreen이 경고합니다. 추가 정보 → 실행을 누르세요. 코드는 공개되어 있습니다 — GitHub와 zip의 “source” 폴더에.

05잘 안 될 때

  • 로그: data\log.txt (창의 “로그” 버튼).
  • 처음부터 다시: 프로그램을 닫고 data 폴더를 삭제하세요.
  • 게임이 업데이트되면 프로그램이 알아서 게임을 다시 읽습니다. 그래도 모드가 만들어지지 않으면 — 여기서 새 버전을 찾아보세요.
  • 삭제: Frosty Mod Manager에서 모드를 끄고 프로그램 폴더를 삭제하세요.
버그 신고 무엇을 했는지 적고 data\log.txt 끝부분을 붙여 넣으세요
