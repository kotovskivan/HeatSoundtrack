HEATSoundtrack

把你自己的歌曲放进 Need for Speed Heat —— 作为新曲目，就在游戏曲目旁边。

即将推出源代码

免费 · Windows 10/11 · 仅限单人游戏 · 粉丝制作

功能

你的歌曲

mp3、flac、wav、ogg、m4a —— 作为全新曲目加入。游戏原有的曲目保持不变。

白天 · 夜晚

勾选每首歌在哪里播放：车库、白天城市、夜晚城市、白天比赛、夜晚比赛。

游戏曲目

任意游戏曲目都可以开启或关闭 —— 每个场景单独设置。

YouTube · YT Music

粘贴单曲、播放列表或专辑的链接 —— 也可以一次粘贴多个链接。如果是 MV 链接，程序会从 YT Music 获取同一首歌。

一个模组

只为 Frosty Mod Manager 生成一个模组。不修改游戏文件。配置：不同的曲目组合，一键切换。

13 种语言

程序窗口支持 13 种语言。zip 里没有音乐，也没有游戏文件 —— 歌曲由你自己提供。

需要准备

  1. Windows 10 或 11 —— 系统自带 Microsoft Edge，程序窗口要用到它。
  2. Need for Speed Heat —— Steam 或 EA app。
  3. Frosty Mod Manager，HarGabt 的版本 —— 发布页。先运行一次并选择游戏。
  4. 游戏的加密密钥 —— Nexus Mods 上的 NFS Heat Frosty Key：把 NFSHEAT.key 放进 Frosty Mod Manager 文件夹。

使用方法

  1. 把 zip 的全部内容解压到一个普通文件夹 —— 桌面、文档、D:\Mods… —— 不要解压到 Program Files。
  2. 运行 Heat Soundtrack.exe，选择语言并接受条款。首次启动会读取游戏 —— 需要几分钟，只有这一次。
  3. + 添加歌曲 → 选择文件 → 勾选播放场景 → 保存。或者 ▶ 从 YT Music 导入 → 粘贴链接 → 下载。
  4. 歌曲都放在程序旁边的 Music 文件夹里 —— 每首歌一个带编号的文件夹：歌曲文件和一张封面图片。
  5. 生成模组。模组会出现在 Frosty Mod Manager 的列表里。
  6. 在 Frosty Mod Manager 中：勾选 Heat Soundtrack，关闭其他音乐模组，点击 Launch。

仅限离线。 模组仅用于单人游戏。联机之前，请先不带模组启动游戏 —— 带模组联机可能导致你的 EA 账号被封。

Windows SmartScreen 可能会提示“未知发布者”：本程序没有付费证书。点击 更多信息 → 仍要运行。源代码在 GitHub 上。
