01功能

你的歌曲

mp3、flac、wav、ogg、m4a —— 以你自己的名称作为新曲目加入，不会替换游戏原有曲目。每首歌的音量 0–300%，带“自动”和过载保护。

YouTube · YT Music · Spotify

粘贴单曲、播放列表或专辑链接，也可以一次多个链接或 .txt 列表。程序会自动下载；MV 链接会从 YT Music 取同一首歌，没有片头和小剧情。 也可以用 Spotify 链接：列表来自 Spotify，歌曲来自 YT Music。

GO 时起 Drop

用你的歌开始比赛：过场的四个画面和 3-2-1 倒计时伴着它播放，GO! 之后马上进入 Drop。Drop 由程序自动找到，也可以在波形上拖动。

车库 · 城市 · 比赛

勾选每首歌在哪里播放：车库、白天城市、夜晚城市、白天比赛、夜晚比赛。游戏原有曲目也一样，每个场景分别设置。驶出车库 —— 驶出车库时播放你选的那一段。可为不同的音乐组合建立配置。

一个模组

为 Frosty Mod Manager 生成一个模组。游戏文件不会被修改 —— 关闭模组，游戏就恢复原样。关闭旁白 —— Ana 和驾驶中的对话都会安静下来。

干净的 zip

zip 里没有音乐，也没有游戏文件：歌曲是你自己的，游戏曲目和背景从你自己的游戏中读取。

03你需要

  1. Windows 10 或 11 —— 系统自带 Microsoft Edge，程序窗口要用到它。
  2. Need for Speed Heat —— Steam 或 EA app。
  3. Frosty Mod Manager，HarGabt 的版本 —— 发布页。先运行一次并选择游戏。
  4. 游戏的加密密钥 —— Nexus Mods 上的 NFS Heat Frosty Key：把 NFSHEAT.key 放进 Frosty Mod Manager 文件夹。

04如何把自己的音乐加入 NFS Heat

  1. 把整个 zip 解压到普通文件夹 —— 桌面、文档、D:\Mods… 不要放在 Program Files。
  2. 运行 Heat Soundtrack.exe，选择语言并接受条款。首次启动会读取游戏 —— 需要几分钟，只有这一次。
  3. + 添加歌曲 → 选择文件 → 勾选播放场景；比赛检查 Drop，车库检查驶出段 → 保存。或者 ▶︎ 从 YT Music 导入 → 粘贴链接（单曲、播放列表、专辑），也可以多个链接或 .txt 列表 → 下载。MV 链接会从 YT Music 取同一首歌，没有片头和小剧情。导入播放列表前会显示歌曲数、已有数量、所需时间和空间；已有的歌曲会跳过。.txt 列表：标题,艺术家,链接;（用拉丁字母）—— 程序里有示例文件。歌曲放在程序旁边的 Music 文件夹里，每首一个编号文件夹：Music\1\、Music\2\… 也可以手动：新建一个编号文件夹，放入歌曲文件和一张图片。封面只在本程序中显示，不会进入游戏。
  4. 生成模组。模组会出现在 Frosty Mod Manager 的列表里。
  5. 在 Frosty Mod Manager 中勾选 Heat Soundtrack，关闭其他音乐模组，点击 Launch。

仅限离线

模组只用于单人游戏。玩 Online 前，请不带模组启动游戏。带模组玩 Online 可能导致 EA 账号被封。

“Windows 已保护你的电脑”

程序没有付费证书签名，所以 SmartScreen 会发出警告。点击 更多信息 → 仍要运行。代码是开源的 —— 在 GitHub 和 zip 中的 “source” 文件夹里。

05如果出了问题

  • 日志在 data\log.txt（窗口里的 “日志” 按钮）。
  • 重新开始：关闭程序并删除 data 文件夹。
  • 游戏更新后，程序会自动重新读取游戏。如果模组仍然无法生成 —— 请来这里找新版本。
  • 卸载：在 Frosty Mod Manager 中关闭模组，然后删除程序文件夹。
