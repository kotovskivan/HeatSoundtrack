HEATSoundtrack

Need for Speed Heat に自分の曲を — 新しい曲として、ゲームの曲のすぐ隣に。

近日公開ソースコード

無料 · Windows 10/11 · シングルプレイ専用 · ファンメイド

できること

自分の曲

mp3、flac、wav、ogg、m4a — 新しい曲として追加します。ゲームの曲はそのまま残ります。

昼 · 夜

曲ごとに流れる場所をチェックで選べます：ガレージ、昼の街、夜の街、昼のレース、夜のレース。

ゲームの曲

ゲームのどの曲もオン／オフできます — 場所ごとに別々に。

YouTube · YT Music

曲・プレイリスト・アルバムのリンクを貼り付けるだけ — 複数のリンクをまとめて貼っても OK。MV のリンクなら、同じ曲を YT Music から取得します。

MOD は 1 つ

Frosty Mod Manager 用の MOD を 1 つだけ作成します。ゲームのファイルは変更しません。プロファイル：曲のセットを使い分けて、ワンクリックで切り替え。

13 言語

ウィンドウは 13 言語に対応。zip に音楽やゲームのファイルは入っていません — 曲はあなたが用意します。

必要なもの

  1. Windows 10 または 11 — Microsoft Edge が標準で入っていて、ウィンドウの表示に使います。
  2. Need for Speed Heat — Steam または EA app。
  3. Frosty Mod Manager（HarGabt 版） — リリース。一度起動して、ゲームを選んでおいてください。
  4. ゲームの暗号化キー — Nexus Mods の NFS Heat Frosty Key：NFSHEAT.key を Frosty Mod Manager のフォルダーに入れます。

使い方

  1. zip を丸ごと普通のフォルダーに展開してください — デスクトップ、ドキュメント、D:\Mods… など。Program Files の中には展開しないでください。
  2. Heat Soundtrack.exe を起動し、言語を選んで利用条件に同意します。初回起動時はゲームを読み込みます — 数分かかりますが、最初の一回だけです。
  3. + 曲を追加 → ファイルを選ぶ → 流れる場所をチェック → 保存。または ▶ YT Music から → リンクを貼り付け → ダウンロード。
  4. 曲はプログラムの隣にある Music フォルダーに入ります — 1 曲につき番号付きのフォルダーが 1 つ：曲のファイルとジャケット用の画像。
  5. MOD を作成。MOD が Frosty Mod Manager のリストに表示されます。
  6. Frosty Mod Manager で Heat Soundtrack にチェックを入れ、ほかの音楽 MOD をオフにして、Launch を押します。

オフライン専用。 MOD はシングルプレイ専用です。オンラインで遊ぶ前に、MOD なしでゲームを起動してください — MOD を入れたままオンラインで遊ぶと、EA アカウントが BAN される可能性があります。

Windows SmartScreen が「不明な発行元」と警告することがあります：このプログラムには有料の証明書がないためです。詳細情報 → 実行 をクリックしてください。ソースコードは GitHub にあります。
