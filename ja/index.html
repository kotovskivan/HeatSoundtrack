01できること

自分の曲

mp3、flac、wav、ogg、m4a を、自分のタイトル付きの新しいトラックとして追加。ゲームの曲を置き換えません。曲ごとの音量は 0〜300%、「自動」と過負荷保護つき。

YouTube · YT Music · Spotify

曲・プレイリスト・アルバムのリンク、複数のリンク、.txt リストを貼るだけ。ダウンロードはプログラムが自動で行います。MV のリンクなら YT Music の同じ曲を、イントロや寸劇なしで取得します。 Spotify のリンクも使えます：リストは Spotify から、曲は YT Music から。

GO でドロップ

自分の曲でレーススタート：カットシーンの 4 カットとカウントダウン 3-2-1 がその曲に乗り、GO! の直後にドロップが来ます。ドロップはプログラムが自動で見つけ、波形上で動かせます。

ガレージ · 街 · レース

曲ごとに流れる場所をチェックで選べます：ガレージ、昼の街、夜の街、昼のレース、夜のレース。ゲームの曲も同じく、場所ごとに設定。ガレージから出発 —— 出発するときに流れる、自分で選んだパート。音楽セットごとにプロファイルも作れます。

MOD はひとつ

Frosty Mod Manager 用の MOD をひとつ作ります。ゲームファイルは変更しません — MOD をオフにすれば元どおりです。ナレーションなし —— Ana と走行中の会話が静かになります。

クリーンな zip

zip に音楽やゲームファイルは入っていません。曲はあなたのもの、ゲームの曲と背景はあなたのゲームから読み込みます。

02スクリーンショット

03必要なもの

  1. Windows 10 または 11 — Microsoft Edge が標準で入っていて、ウィンドウの表示に使います。
  2. Need for Speed Heat — Steam または EA app。
  3. Frosty Mod Manager（HarGabt 版） — リリース。一度起動して、ゲームを選んでおいてください。
  4. ゲームの暗号化キー — Nexus Mods の NFS Heat Frosty Key：NFSHEAT.key を Frosty Mod Manager のフォルダーに入れます。

04NFS Heat に自分の音楽を入れる方法

  1. zip をまるごと普通のフォルダーに展開 — デスクトップ、ドキュメント、D:\Mods… Program Files には入れないでください。
  2. Heat Soundtrack.exe を起動し、言語を選んで利用条件に同意します。初回起動時はゲームを読み込みます — 数分かかりますが、最初の一回だけです。
  3. + 曲を追加 → ファイルを選ぶ → 流れる場所をチェック。レースはドロップ、ガレージは出発パートを確認 → 保存。または ▶︎ YT Music から → リンクを貼り付け（曲、プレイリスト、アルバム）。複数のリンクや .txt リストも可 → ダウンロード。MV のリンクなら、YT Music の同じ曲をイントロや寸劇なしで取得します。プレイリストの前に、曲数・すでにある曲・時間・容量を表示し、すでにある曲はスキップします。.txt リスト：タイトル,アーティスト,リンク;（ラテン文字で）— サンプルファイルはプログラム内にあります。曲はプログラムの隣の Music フォルダーに、1 曲ずつ番号付きフォルダーで入っています：Music\1\、Music\2\… 手動でも OK：番号付きの新しいフォルダーに曲ファイルと画像を入れるだけ。ジャケットはこのプログラム内だけのもので、ゲームには入りません。
  4. MOD を作成。MOD が Frosty Mod Manager のリストに表示されます。
  5. Frosty Mod Manager で Heat Soundtrack にチェック、ほかの音楽 MOD はオフにして Launch。

オフライン専用

MOD はシングルプレイ用です。オンラインで遊ぶ前に、MOD なしでゲームを起動してください。MOD を入れたままオンラインで遊ぶと、EA アカウントが BAN される可能性があります。

「Windows によって PC が保護されました」

有料の証明書で署名していないため、SmartScreen が警告を出します。詳細情報 → 実行 をクリックしてください。コードは公開しています — GitHub と zip 内の「source」フォルダーにあります。

05うまく動かないとき

  • ログは data\log.txt（ウィンドウの「ログ」ボタン）。
  • 最初からやり直す：プログラムを閉じて data フォルダーを削除。
  • ゲームのアップデート後は、プログラムが自動でゲームを読み直します。それでも MOD が作れない場合は、ここで新しいバージョンを探してください。
  • 削除：Frosty Mod Manager で MOD をオフにして、プログラムのフォルダーを削除。
バグを報告 何をしたかを書いて、data\log.txt の最後の部分を貼り付けてください
