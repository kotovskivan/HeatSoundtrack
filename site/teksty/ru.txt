# --- как пользоваться ---
how_h = Как пользоваться
s1 = Распакуй **весь** zip в обычную папку — Рабочий стол, Документы, D:\Mods… Не в Program Files.
s2 = Запусти **Heat Soundtrack.exe**, выбери язык и прими условия. Первый запуск читает игру — несколько минут, только один раз.
s3 = **+ ДОБАВИТЬ ПЕСНЮ** → выбери файл → поставь галочки, где играет, GO и финиш → **Сохранить**.
s3yt = Или **▶ ИЗ YT MUSIC** → вставь ссылку (песня, плейлист, альбом), много ссылок или список .txt → **Скачать**.
s3ytsub = Ссылка на клип — программа возьмет ту же песню из YT Music, без вступлений и сценок. Перед плейлистом покажет, сколько песен, сколько уже есть, сколько времени и места; те, что уже есть, пропустит. Список .txt: Название,Исполнитель,Ссылка; (латиницей) — пример файла есть в программе.
s3sub = Песни лежат в папке **Music** рядом с программой, каждая в папке с номером: Music\1\, Music\2\… Можно и вручную: новая папка с номером, в ней файл песни и картинка. Обложка — только для программы: в игру она не попадает.
s4 = **СОБРАТЬ МОД**. Мод появится в списке Frosty Mod Manager.
s5 = В Frosty Mod Manager: галочка на **Heat Soundtrack**, другие музыкальные моды выключи, **Launch**.
off_h = Только офлайн.
off = Моды — для одиночной игры. Перед онлайном запускай игру **без модов**. Онлайн с модами — риск бана аккаунта EA.
ss = Программа не подписана платным сертификатом, поэтому SmartScreen предупреждает. Нажми **Подробнее** → **Выполнить в любом случае**. Код открыт — на [GitHub](github) и в папке «source» в zip.
