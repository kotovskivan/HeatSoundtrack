# --- what it does ---
what_h = Ce qu'il fait
f1t = Tes chansons
f1 = mp3, flac, wav, ogg, m4a — comme **nouveaux** titres avec ton nom, sans remplacer les titres du jeu. Volume de chaque chanson de 0 à 300 %, avec Auto et protection contre la saturation.
f2t = Drop sur le GO
f2 = Départ avec ta chanson : les quatre plans de la cinématique et le compte à rebours 3-2-1 passent dessus, et le drop tombe juste après le GO!. Le programme trouve le drop tout seul — tu peux le déplacer sur l'onde.
f3t = Garage · Ville · Courses
f3 = Coche où passe chaque chanson : garage, ville de jour, ville de nuit, courses de jour, courses de nuit. Les titres du jeu aussi, séparément pour chaque endroit. **Sortie du garage** — ton passage de la chanson quand tu sors. Des profils pour différentes playlists.
f4t = Un seul mod
f4 = Crée un seul mod pour Frosty Mod Manager. Les fichiers du jeu ne changent pas — désactive le mod et le jeu redevient comme avant. **Sans narrateur** — Ana et les bavardages en route se taisent.
f5t = Zip propre
f5 = Ni musique ni fichiers du jeu dans le zip : les chansons sont à toi, les titres et les fonds sont lus depuis ton propre jeu.
f6t = YouTube · YT Music · Spotify
f6 = Colle le lien d'une chanson, d'une playlist ou d'un album — ou plusieurs liens, ou une liste .txt. Le programme télécharge tout seul ; un lien de clip prend la même chanson sur YT Music, sans intro ni saynètes. Un lien Spotify marche aussi : la liste vient de Spotify, les chansons de YT Music.

# --- how to use ---
how_h = Comment l'utiliser
s1 = Décompresse le zip **entier** dans un dossier normal — Bureau, Documents, D:\Mods… Pas dans Program Files.
s2 = Lance **Heat Soundtrack.exe**, choisis la langue et accepte les conditions. Le premier lancement lit le jeu — quelques minutes, une seule fois.
s3 = **+ AJOUTER UNE CHANSON** → choisis un fichier → coche où elle passe ; pour les courses vérifie le drop, pour le garage la sortie → **Enregistrer**.
s3yt = Ou **▶ DEPUIS YT MUSIC** → colle un lien (chanson, playlist, album), plusieurs liens ou une liste .txt → **Télécharger**.
s3ytsub = Lien de clip — le programme prend la même chanson sur YT Music, sans intro ni saynètes. Avant une playlist, il montre combien de chansons, combien tu en as déjà, le temps et la place ; celles que tu as déjà sont sautées. Liste .txt : Titre,Artiste,Lien; (lettres latines) — le programme montre un fichier d'exemple.
s3sub = Les chansons sont dans le dossier **Music** à côté du programme, chacune dans un dossier numéroté : Music\1\, Music\2\… À la main aussi : un nouveau dossier numéroté avec le fichier de la chanson et une image. La pochette sert seulement au programme : elle ne va pas dans le jeu.
s4 = **CRÉER LE MOD**. Le mod apparaît dans la liste de Frosty Mod Manager.
s5 = Dans Frosty Mod Manager : coche **Heat Soundtrack**, désactive les autres mods de musique, **Launch**.
off_h = Hors ligne uniquement.
off = Les mods sont pour le jeu en solo. Avant de jouer en ligne, lance le jeu **sans mods**. Jouer en ligne avec des mods peut faire bannir ton compte EA.
ss = Le programme n'est pas signé avec un certificat payant, donc SmartScreen affiche un avertissement. Clique sur **Informations complémentaires** → **Exécuter quand même**. Le code est ouvert — sur [GitHub](github) et dans le dossier « source » du zip.
