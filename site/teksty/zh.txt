# --- what it does ---
what_h = 功能
f1t = 你的歌曲
f1 = mp3、flac、wav、ogg、m4a —— 以你自己的名称作为**新**曲目加入，不会替换游戏原有曲目。每首歌的音量 0–300%，带“自动”和过载保护。
f2t = GO 时起 Drop
f2 = 用你的歌开始比赛：过场的四个画面和 3-2-1 倒计时伴着它播放，GO! 之后马上进入 Drop。Drop 由程序自动找到，也可以在波形上拖动。
f3t = 车库 · 城市 · 比赛
f3 = 勾选每首歌在哪里播放：车库、白天城市、夜晚城市、白天比赛、夜晚比赛。游戏原有曲目也一样，每个场景分别设置。**驶出车库** —— 驶出车库时播放你选的那一段。可为不同的音乐组合建立配置。
f4t = 一个模组
f4 = 为 Frosty Mod Manager 生成一个模组。游戏文件不会被修改 —— 关闭模组，游戏就恢复原样。**关闭旁白** —— Ana 和驾驶中的对话都会安静下来。
f5t = 干净的 zip
f5 = zip 里没有音乐，也没有游戏文件：歌曲是你自己的，游戏曲目和背景从你自己的游戏中读取。
f6t = YouTube · YT Music · Spotify
f6 = 粘贴单曲、播放列表或专辑链接，也可以一次多个链接或 .txt 列表。程序会自动下载；MV 链接会从 YT Music 取同一首歌，没有片头和小剧情。 也可以用 Spotify 链接：列表来自 Spotify，歌曲来自 YT Music。

# --- how to use ---
how_h = 使用方法
s1 = 把**整个** zip 解压到普通文件夹 —— 桌面、文档、D:\Mods… 不要放在 Program Files。
s2 = 运行 **Heat Soundtrack.exe**，选择语言并接受条款。首次启动会读取游戏 —— 需要几分钟，只有这一次。
s3 = **+ 添加歌曲** → 选择文件 → 勾选播放场景；比赛检查 Drop，车库检查驶出段 → **保存**。
s3yt = 或者 **▶ 从 YT Music 导入** → 粘贴链接（单曲、播放列表、专辑），也可以多个链接或 .txt 列表 → **下载**。
s3ytsub = MV 链接会从 YT Music 取同一首歌，没有片头和小剧情。导入播放列表前会显示歌曲数、已有数量、所需时间和空间；已有的歌曲会跳过。.txt 列表：标题,艺术家,链接;（用拉丁字母）—— 程序里有示例文件。
s3sub = 歌曲放在程序旁边的 **Music** 文件夹里，每首一个编号文件夹：Music\1\、Music\2\… 也可以手动：新建一个编号文件夹，放入歌曲文件和一张图片。封面只在本程序中显示，不会进入游戏。
s4 = **生成模组**。模组会出现在 Frosty Mod Manager 的列表里。
s5 = 在 Frosty Mod Manager 中勾选 **Heat Soundtrack**，关闭其他音乐模组，点击 **Launch**。
off_h = 仅限离线。
off = 模组只用于单人游戏。玩 Online 前，请**不带模组**启动游戏。带模组玩 Online 可能导致 EA 账号被封。
ss = 程序没有付费证书签名，所以 SmartScreen 会发出警告。点击 **更多信息** → **仍要运行**。代码是开源的 —— 在 [GitHub](github) 和 zip 中的 “source” 文件夹里。
