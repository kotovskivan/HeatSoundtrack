# --- what it does ---
what_h = Was es macht
f1t = Deine Songs
f1 = mp3, flac, wav, ogg, m4a — als **neue** Tracks mit eigenem Namen, nicht anstelle der Tracks des Spiels. Lautstärke jedes Songs von 0 bis 300 %, mit Auto und Übersteuerungsschutz.
f2t = Drop bei GO
f2 = Rennstart mit deinem Song: die vier Bilder der Zwischensequenz und der Countdown 3-2-1 laufen darüber, der Drop knallt direkt nach GO!. Den Drop findet das Programm selbst — verschieben kannst du ihn auf der Welle.
f3t = Garage · Stadt · Rennen
f3 = Per Häkchen wählst du, wo jeder Song läuft: Garage, Stadt am Tag, Stadt in der Nacht, Rennen am Tag, Rennen in der Nacht. Die Tracks des Spiels genauso, für jeden Ort getrennt. **Garagenausfahrt** — dein Stück des Songs, wenn du losfährst. Profile für verschiedene Musik-Sets.
f4t = Ein Mod
f4 = Baut einen Mod für den Frosty Mod Manager. Spieldateien bleiben unverändert — Mod aus, und alles ist wie vorher. **Ohne Sprecher** — Ana und die Fahrgespräche verstummen.
f5t = Sauberes Zip
f5 = Keine Musik und keine Spieldateien im Zip: die Songs sind deine, Tracks und Hintergründe liest das Programm aus deinem Spiel.
f6t = YouTube · YT Music · Spotify
f6 = Füg einen Link zu einem Song, einer Playlist oder einem Album ein — oder viele Links, oder eine .txt-Liste. Das Programm lädt selbst herunter; ein Musikvideo-Link holt denselben Song von YT Music, ohne Intro und Szenen. Ein Spotify-Link geht auch: die Liste kommt von Spotify, die Songs von YT Music.

# --- how to use ---
how_h = So geht's
s1 = Das **ganze** Zip in einen normalen Ordner entpacken — Desktop, Dokumente, D:\Mods… Nicht nach Program Files.
s2 = Starte **Heat Soundtrack.exe**, wähle die Sprache und nimm die Bedingungen an. Der erste Start liest das Spiel — ein paar Minuten, nur einmal.
s3 = **+ SONG HINZUFÜGEN** → Datei wählen → Häkchen setzen, wo er läuft; bei Rennen den Drop prüfen, bei der Garage die Ausfahrt → **Speichern**.
s3yt = Oder **▶ AUS YT MUSIC** → Link einfügen (Song, Playlist, Album), viele Links oder eine .txt-Liste → **Herunterladen**.
s3ytsub = Musikvideo-Link — das Programm nimmt denselben Song von YT Music, ohne Intro und Szenen. Vor einer Playlist zeigt es, wie viele Songs, wie viele du schon hast, Zeit und Platz; vorhandene werden übersprungen. .txt-Liste: Titel,Interpret,Link; (lateinische Buchstaben) — eine Beispieldatei gibt es im Programm.
s3sub = Die Songs liegen im Ordner **Music** neben dem Programm, jeder in einem nummerierten Ordner: Music\1\, Music\2\… Geht auch von Hand: neuer nummerierter Ordner mit Musikdatei und Bild. Das Cover ist nur fürs Programm — ins Spiel kommt es nicht.
s4 = **MOD BAUEN**. Der Mod erscheint in der Liste des Frosty Mod Manager.
s5 = Im Frosty Mod Manager **Heat Soundtrack** anhaken, andere Musik-Mods aus, **Launch**.
off_h = Nur offline.
off = Mods sind fürs Einzelspieler-Spiel. Vor dem Online-Spiel das Spiel **ohne Mods** starten. Online mit Mods droht eine Sperre des EA-Kontos.
ss = Das Programm ist nicht mit einem kostenpflichtigen Zertifikat signiert, deshalb warnt SmartScreen. **Weitere Informationen** → **Trotzdem ausführen**. Der Code ist offen — auf [GitHub](github) und im Ordner „source“ im Zip.
