# --- what it does ---
what_h = Co robi
f1t = Twoje piosenki
f1 = mp3, flac, wav, ogg, m4a — jako **nowe** utwory z własną nazwą, a nie zamiast utworów gry. Głośność każdej piosenki od 0 do 300 %, z „Auto” i ochroną przed przesterowaniem.
f2t = Drop na GO
f2 = Start wyścigu z twoją piosenką: cztery ujęcia przerywnika i odliczanie 3-2-1 lecą pod nią, a drop uderza tuż po GO!. Drop program znajduje sam — przesuniesz go na fali.
f3t = Garaż · Miasto · Wyścigi
f3 = Zaznaczasz, gdzie gra każda piosenka: garaż, miasto w dzień, miasto w nocy, wyścigi w dzień, wyścigi w nocy. Utwory gry tak samo — osobno dla każdego miejsca. **Wyjazd z garażu** — twój fragment piosenki, gdy wyjeżdżasz. Profile dla różnych zestawów muzyki.
f4t = Jeden mod
f4 = Buduje jeden mod do Frosty Mod Manager. Pliki gry się nie zmieniają — wyłączysz mod i gra jest jak dawniej. **Bez narratora** — milkną Ana i rozmowy w trakcie jazdy.
f5t = Czysty zip
f5 = W zipie nie ma muzyki ani plików gry: piosenki są twoje, utwory i tła program czyta z twojej gry.
f6t = YouTube · YT Music · Spotify
f6 = Wklej link do piosenki, playlisty albo albumu — albo wiele linków, albo listę .txt. Program sam pobierze; link do teledysku pobiera tę samą piosenkę z YT Music, bez intra i scenek. Link ze Spotify też działa: lista pochodzi ze Spotify, piosenki z YT Music.

# --- how to use ---
how_h = Jak używać
s1 = Rozpakuj **cały** zip do zwykłego folderu — Pulpit, Dokumenty, D:\Mods… Nie do Program Files.
s2 = Uruchom **Heat Soundtrack.exe**, wybierz język i zaakceptuj warunki. Pierwsze uruchomienie czyta grę — kilka minut, tylko raz.
s3 = **+ DODAJ PIOSENKĘ** → wybierz plik → zaznacz, gdzie gra; przy wyścigach sprawdź drop, przy garażu — wyjazd → **Zapisz**.
s3yt = Albo **▶ Z YT MUSIC** → wklej link (piosenka, playlista, album), wiele linków albo listę .txt → **Pobierz**.
s3ytsub = Link do teledysku — program weźmie tę samą piosenkę z YT Music, bez intra i scenek. Przed playlistą pokaże, ile piosenek, ile już masz, ile czasu i miejsca; te, które już są, pominie. Lista .txt: Tytuł,Wykonawca,Link; (alfabetem łacińskim) — przykładowy plik jest w programie.
s3sub = Piosenki leżą w folderze **Music** obok programu, każda w folderze z numerem: Music\1\, Music\2\… Można też ręcznie: nowy folder z numerem, w nim plik piosenki i obrazek. Okładka jest tylko dla programu — do gry nie trafia.
s4 = **ZBUDUJ MODA**. Mod pojawi się na liście we Frosty Mod Manager.
s5 = We Frosty Mod Manager zaznacz **Heat Soundtrack**, wyłącz inne mody muzyczne, **Launch**.
off_h = Tylko offline.
off = Mody są do gry jednoosobowej. Przed grą Online uruchom grę **bez modów**. Gra Online z modami grozi banem konta EA.
