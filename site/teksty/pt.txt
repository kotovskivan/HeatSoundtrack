# --- how to use ---
how_h = Como usar
s1 = Descompacte o zip **inteiro** numa pasta comum — Área de Trabalho, Documentos, D:\Mods… — não em Program Files.
s2 = Abra **Heat Soundtrack.exe**, escolha o idioma e aceite os termos. Na primeira vez ele lê o jogo — alguns minutos, só uma vez.
s3 = **+ ADICIONAR MÚSICA** → escolha um arquivo → marque onde toca → **Salvar**. Ou **▶ DO YT MUSIC** → cole um link → **Baixar**.
s4 = As músicas ficam na pasta **Music** ao lado do programa — uma pasta numerada por música: o arquivo da música e uma imagem de capa. A capa é só para o programa — não vai para o mod nem para o jogo (o Heat não tem capas de faixas).
s5 = **GERAR MOD**. O mod aparece na lista do Frosty Mod Manager.
s6 = No Frosty Mod Manager: marque **Heat Soundtrack**, desative outros mods de música, clique em **Launch**.
off_h = Só offline.
off = Mods são para o modo single-player. Antes de entrar online, abra o jogo sem mods — jogar online com mods pode fazer sua conta EA ser banida.
ss = O Windows SmartScreen pode avisar sobre um editor desconhecido: o programa não tem certificado pago. Clique em **Mais informações** → **Executar assim mesmo**. O código-fonte está no [GitHub](github).
