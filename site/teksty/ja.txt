# --- what it does ---
what_h = できること
f1t = 自分の曲
f1 = mp3、flac、wav、ogg、m4a を、自分のタイトル付きの**新しい**トラックとして追加。ゲームの曲を置き換えません。1 つの MOD に数百曲。
f2t = GO でドロップ
f2 = スタート：17 秒のカットシーン + 3.45 秒のカウントダウン、GO の瞬間にドロップ。GO マーカーはマウスでドラッグ。フィニッシュ用の短いパートも。
f3t = ガレージ · 街 · レース
f3 = 曲ごとに流れる場所をチェックで選べます：ガレージ、昼の街、夜の街、昼のレース、夜のレース。ゲームの曲も同じく、場所ごとに設定。音楽セットごとにプロファイルも作れます。
f4t = MOD はひとつ
f4 = Frosty Mod Manager 用の MOD をひとつ作ります。ゲームファイルは変更しません — MOD をオフにすれば元どおりです。
f5t = クリーンな zip
f5 = zip に音楽やゲームファイルは入っていません。曲はあなたのもの、ゲームの曲はあなたのゲームから読み込みます。▶ — ゲーム内の曲を 30 秒試聴（インターネットが必要）。
f6t = YouTube · YT Music · Spotify
f6 = 曲・プレイリスト・アルバムのリンク、複数のリンク、.txt リストを貼るだけ。ダウンロードはプログラムが自動で行います。MV のリンクなら YT Music の同じ曲を、イントロや寸劇なしで取得します。 Spotify のリンクも使えます：リストは Spotify から、曲は YT Music から。

# --- how to use ---
how_h = 使い方
s1 = zip を**まるごと**普通のフォルダーに展開 — デスクトップ、ドキュメント、D:\Mods… Program Files には入れないでください。
s2 = **Heat Soundtrack.exe** を起動し、言語を選んで利用条件に同意します。初回起動時はゲームを読み込みます — 数分かかりますが、最初の一回だけです。
s3 = **+ 曲を追加** → ファイルを選ぶ → 流れる場所をチェック、GO とフィニッシュを設定 → **保存**。
s3yt = または **▶ YT Music から** → リンクを貼り付け（曲、プレイリスト、アルバム）。複数のリンクや .txt リストも可 → **ダウンロード**。
s3ytsub = MV のリンクなら、YT Music の同じ曲をイントロや寸劇なしで取得します。プレイリストの前に、曲数・すでにある曲・時間・容量を表示し、すでにある曲はスキップします。.txt リスト：タイトル,アーティスト,リンク;（ラテン文字で）— サンプルファイルはプログラム内にあります。
s3sub = 曲はプログラムの隣の **Music** フォルダーに、1 曲ずつ番号付きフォルダーで入っています：Music\1\、Music\2\… 手動でも OK：番号付きの新しいフォルダーに曲ファイルと画像を入れるだけ。ジャケットはこのプログラム内だけのもので、ゲームには入りません。
s4 = **MOD を作成**。MOD が Frosty Mod Manager のリストに表示されます。
s5 = Frosty Mod Manager で **Heat Soundtrack** にチェック、ほかの音楽 MOD はオフにして **Launch**。
off_h = オフライン専用。
off = MOD はシングルプレイ用です。オンラインで遊ぶ前に、**MOD なし**でゲームを起動してください。MOD を入れたままオンラインで遊ぶと、EA アカウントが BAN される可能性があります。
ss = 有料の証明書で署名していないため、SmartScreen が警告を出します。**詳細情報** → **実行** をクリックしてください。コードは公開しています — [GitHub](github) と zip 内の「source」フォルダーにあります。
