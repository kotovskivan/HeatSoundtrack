# --- how to use ---
how_h = 사용법
s1 = zip을 **통째로** 일반 폴더에 압축 해제하세요 — 바탕 화면, 문서, D:\Mods… — Program Files 말고요.
s2 = **Heat Soundtrack.exe**를 실행하고 언어를 고른 뒤 약관에 동의하세요. 처음 실행할 때 게임을 읽어요 — 몇 분 걸리지만 딱 한 번이에요.
s3 = **+ 노래 추가** → 파일 선택 → 재생 위치 체크 → **저장**. 또는 **▶ YT Music에서** → 링크 붙여 넣기 → **다운로드**.
s4 = 노래는 프로그램 옆 **Music** 폴더에 있어요 — 노래마다 번호 폴더 하나: 노래 파일과 커버 그림.
s5 = **모드 만들기**. 모드가 Frosty Mod Manager 목록에 나타나요.
s6 = Frosty Mod Manager에서: **Heat Soundtrack**에 체크하고, 다른 음악 모드는 끄고, **Launch**를 누르세요.
off_h = 오프라인 전용.
off = 모드는 싱글 플레이 전용이에요. 온라인에 접속하기 전에 모드 없이 게임을 실행하세요 — 모드를 켠 채 온라인을 하면 EA 계정이 정지될 수 있어요.
ss = Windows SmartScreen이 알 수 없는 게시자라고 경고할 수 있어요: 이 프로그램에는 유료 인증서가 없거든요. **추가 정보** → **실행**을 클릭하세요. 소스 코드는 [GitHub](github)에 있어요.
