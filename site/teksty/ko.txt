# --- how to use ---
how_h = 사용법
s1 = zip **전체**를 일반 폴더에 압축 해제 — 바탕 화면, 문서, D:\Mods… Program Files에는 넣지 마세요.
s2 = **Heat Soundtrack.exe**를 실행하고 언어를 고른 뒤 약관에 동의하세요. 처음 실행할 때 게임을 읽어요 — 몇 분 걸리지만 딱 한 번이에요.
s3 = **+ 노래 추가** → 파일 선택 → 재생 위치 체크, GO와 결승 설정 → **저장**.
s3yt = 또는 **▶ YT Music에서** → 링크 붙여 넣기(노래, 재생목록, 앨범). 여러 링크나 .txt 목록도 가능 → **다운로드**.
s3ytsub = 뮤직비디오 링크면 YT Music의 같은 노래를 인트로와 장면 없이 가져옵니다. 플레이리스트 전에는 곡 수, 이미 있는 곡, 시간과 용량을 보여 주고, 이미 있는 곡은 건너뜁니다. .txt 목록: 제목,아티스트,링크; (라틴 문자로) — 예시 파일은 프로그램에 있습니다.
s3sub = 노래는 프로그램 옆의 **Music** 폴더에, 한 곡씩 번호 폴더로 들어 있습니다: Music\1\, Music\2\… 직접 해도 됩니다: 번호를 붙인 새 폴더에 노래 파일과 이미지를 넣으면 끝. 커버는 이 프로그램에서만 보이고, 게임에는 들어가지 않습니다.
s4 = **모드 만들기**. 모드가 Frosty Mod Manager 목록에 나타나요.
s5 = Frosty Mod Manager에서 **Heat Soundtrack**을 체크하고, 다른 음악 모드는 끈 뒤 **Launch**.
off_h = 오프라인 전용.
off = 모드는 싱글 플레이용입니다. 온라인으로 하기 전에 게임을 **모드 없이** 실행하세요. 모드를 켠 채 온라인을 하면 EA 계정이 정지될 수 있습니다.
ss = 유료 인증서로 서명하지 않아서 SmartScreen이 경고합니다. **추가 정보** → **실행**을 누르세요. 코드는 공개되어 있습니다 — [GitHub](github)와 zip의 “source” 폴더에.
