# --- what it does ---
what_h = What it does
f1t = Your songs
f1 = mp3, flac, wav, ogg, m4a — added as **new** tracks. The game's tracks stay as they are.
f2t = Day · Night
f2 = Tick where each song plays: garage, city by day, city at night, races by day, races at night.
f3t = Game tracks
f3 = Turn any of the game's tracks on or off — separately for every place.
f4t = YouTube · YT Music
f4 = Paste a link to a song, a playlist or an album — or many links at once. A music video link takes the same song from YT Music.
f5t = One mod
f5 = Builds one mod for Frosty Mod Manager. Game files are not changed. Profiles: different sets of tracks, one click to switch.
f6t = 14 languages
f6 = The window speaks 14 languages. No music and no game files in the zip — the songs are yours.

# --- what you need ---
need_h = What you need
n1 = **Windows 10 or 11** — Microsoft Edge is built in, the window uses it.
n2 = **Need for Speed Heat** — Steam or EA app.
n3 = **Frosty Mod Manager**, HarGabt's version — [releases](fmm). Start it once and pick the game.
n4 = The game's encryption key — **NFS Heat Frosty Key** on [Nexus Mods](key): put **NFSHEAT.key** into the Frosty Mod Manager folder.

# --- how to use ---
how_h = How to use
s1 = Unpack the **whole** zip to a normal folder — Desktop, Documents, D:\Mods… — not into Program Files.
s2 = Start **Heat Soundtrack.exe**, choose the language and accept the terms. The first start reads the game — a few minutes, only once.
s3 = **+ ADD SONG** → choose a file → tick where it plays → **Save**. Or **▶ FROM YT MUSIC** → paste a link → **Download**.
s4 = Songs live in the **Music** folder next to the program — one numbered folder per song: the song file and a cover picture. The cover is only for this program — it doesn't go into the mod or the game (Heat has no track covers).
s5 = **BUILD MOD**. The mod appears in Frosty Mod Manager's list.
s6 = In Frosty Mod Manager: tick **Heat Soundtrack**, turn off other music mods, press **Launch**.
off_h = Offline only.
off = Mods are for the single-player game. Before you go online, start the game without mods — playing online with mods can get your EA account banned.
ss = Windows SmartScreen may warn about an unknown publisher: the program has no paid certificate. Click **More info** → **Run anyway**. The source code is on [GitHub](github).
