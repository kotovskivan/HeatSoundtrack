# --- what it does ---
what_h = What it does
f1t = Your songs
f1 = mp3, flac, wav, ogg, m4a — as **new** tracks with your own title, not replacing the game's tracks. Volume of each song from 0 to 300 %, with Auto and overload protection.
f2t = Drop on GO
f2 = Race start with your song: the four cutscene shots and the 3-2-1 countdown play over it, and the drop hits right after GO!. The program finds the drop itself — you can move it on the wave.
f3t = Garage · City · Races
f3 = Tick where each song plays: garage, city by day, city at night, races by day, races at night. Game tracks — the same, separately for each place. **Garage exit** — your part of the song when you drive out. Profiles for different music sets.
f4t = One mod
f4 = Builds one mod for Frosty Mod Manager. Game files are not changed — turn the mod off and the game is as before. **Mute narrator** — Ana and the in-drive chatter go quiet.
f5t = Clean zip
f5 = No music and no game files in the zip: the songs are yours, the game's tracks and backgrounds are read from your own game.
f6t = YouTube · YT Music · Spotify
f6 = Paste a link to a song, a playlist or an album — or many links, or a .txt list. The program downloads them itself; a music video link takes the same song from YT Music, without the intro and skits. A Spotify link works too: the list comes from Spotify, the songs from YT Music.

# --- what you need ---

n1 = **Windows 10 or 11** — Microsoft Edge is built in, the window uses it.
n2 = **Need for Speed Heat** — Steam or EA app.

# --- how to use ---
how_h = How to use
s1 = Unpack the **whole** zip to a normal folder — Desktop, Documents, D:\Mods… Not into Program Files.
s2 = Start **Heat Soundtrack.exe**, choose the language and accept the terms. The first start reads the game — a few minutes, only once.
s3 = **+ ADD SONG** → choose a file → tick where it plays; for races check the drop, for the garage the exit → **Save**.
s3yt = Or **▶ FROM YT MUSIC** → paste a link (song, playlist, album), many links or a .txt list → **Download**.
s3ytsub = A music video link — the program takes the same song from YT Music, without the intro and skits. Before a playlist it shows how many songs, how many you already have, the time and the size; songs you already have are skipped. .txt list: Title,Artist,Link; (Latin letters) — the program shows an example file.
s3sub = Songs live in the **Music** folder next to the program, one numbered folder per song: Music\1\, Music\2\… By hand works too: a new numbered folder with the song file and a picture. The cover is only for the program — it doesn't go into the game.
s4 = **BUILD MOD**. The mod appears in Frosty Mod Manager's list.
s5 = In Frosty Mod Manager: tick **Heat Soundtrack**, turn off other music mods, press **Launch**.
off_h = Offline only.
off = Mods are for the single-player game. Before you go Online, start the game **without mods**. Playing Online with mods can get your EA account banned.
ss = The program is not signed with a paid certificate, so SmartScreen warns about it. Click **More info** → **Run anyway**. The code is open — on [GitHub](github) and in the “source” folder of the zip.
